Cloud infrastructure provides on-demand computing resources over the internet. The three service models are IaaS (virtual machines, storage — like EC2, S3), PaaS (managed platforms — like Heroku, App Engine), and SaaS (complete applications — like Gmail, Salesforce). Key concepts include auto-scaling (adjusting resources based on demand), load balancing (distributing traffic across servers), and regions/availability zones (geographic redundancy). Infrastructure as Code tools like Terraform and CloudFormation define resources declaratively. The shared responsibility model means the cloud provider secures the infrastructure while customers secure their data and applications. Common cost optimization strategies include reserved instances, spot instances, right-sizing, and shutting down non-production resources outside business hours.
