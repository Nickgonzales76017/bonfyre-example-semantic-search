REST (Representational State Transfer) is an architectural style for designing web APIs. RESTful APIs use HTTP methods semantically: GET for retrieval, POST for creation, PUT for full updates, PATCH for partial updates, and DELETE for removal. Resources are identified by URIs and represented in formats like JSON. Key principles include statelessness (each request contains all needed information), uniform interface, and layered system architecture. Good API design includes versioning (v1/v2 in URL or headers), pagination for large collections, proper HTTP status codes (200 OK, 201 Created, 404 Not Found, 422 Unprocessable Entity), HATEOAS for discoverability, and rate limiting to prevent abuse. Authentication typically uses OAuth 2.0 or API keys passed in headers.
