Caching stores frequently accessed data in a faster storage layer to reduce latency and load. The cache hierarchy typically includes browser cache, CDN edge cache, reverse proxy (Nginx, Varnish), application cache (Redis, Memcached), and database query cache. Cache invalidation strategies include TTL-based expiry (simple but may serve stale data), write-through (update cache on every write), write-behind (batch cache writes asynchronously), and cache-aside (application checks cache, falls back to database, then populates cache). The cache stampede problem occurs when many requests simultaneously find an expired cache entry — solutions include locking, probabilistic early expiration, and background refresh. HTTP caching uses headers like Cache-Control, ETag, and Last-Modified. Content-addressable storage (like Git) uses content hashes as keys, making cache invalidation trivial — if the content changes, the hash changes.
