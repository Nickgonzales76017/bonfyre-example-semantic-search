Data science combines statistics, programming, and domain expertise to extract insights from data. The workflow starts with defining a business question, then collecting and cleaning data (often 80% of the work), exploratory data analysis with visualizations, feature engineering, model building, and communicating results to stakeholders. Python and R are the dominant languages, with libraries like pandas for data manipulation, matplotlib and seaborn for visualization, and scikit-learn for machine learning. A/B testing provides causal evidence for business decisions. Common pitfalls include survivorship bias, p-hacking, confusing correlation with causation, and training on data that doesn't represent production conditions. Data pipelines using tools like Apache Airflow automate the flow from raw data to actionable dashboards.
