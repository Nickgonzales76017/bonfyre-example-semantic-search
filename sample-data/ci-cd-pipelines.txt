CI/CD (Continuous Integration/Continuous Delivery) automates the build, test, and deployment pipeline. Continuous Integration merges code changes frequently (at least daily) and runs automated tests on every commit. Continuous Delivery ensures code is always in a deployable state, while Continuous Deployment automatically pushes every passing change to production. Popular platforms include GitHub Actions, GitLab CI, Jenkins, and CircleCI. A typical pipeline: lint → unit tests → build → integration tests → staging deploy → smoke tests → production deploy. Infrastructure as Code ensures environments are reproducible. Blue-green deployments run two identical environments and switch traffic instantly. Canary releases gradually route a percentage of traffic to the new version. Feature flags decouple deployment from release, allowing code to ship disabled and be toggled on independently.
