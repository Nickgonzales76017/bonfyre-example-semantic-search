Linux file permissions control who can read, write, and execute files. Every file has an owner, a group, and permissions for owner (u), group (g), and others (o). The three permission types are read (r=4), write (w=2), and execute (x=1). Numeric notation combines these: 755 means rwxr-xr-x (owner full access, group and others can read and execute). chmod changes permissions, chown changes ownership, and chgrp changes the group. Special permissions include setuid (execute as file owner), setgid (execute as group or inherit directory group), and the sticky bit (only owner can delete files in a directory, commonly used on /tmp). Access Control Lists (ACLs) extend the basic model with fine-grained per-user permissions via setfacl and getfacl. The principle of least privilege dictates granting minimal necessary permissions.
