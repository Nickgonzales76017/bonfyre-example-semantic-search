Docker containers package an application with all its dependencies into a standardized unit for software development. Unlike virtual machines, containers share the host OS kernel and isolate processes at the application level, making them significantly lighter — a container image can be as small as 5 MB compared to a VM's 1+ GB. Dockerfiles define the build steps, images are the read-only templates, and containers are running instances. Docker Compose orchestrates multi-container applications. Key concepts include layers (each instruction creates a cached layer), volumes (persistent storage), and networking (bridge, host, overlay). Containers start in milliseconds vs minutes for VMs because there's no guest OS to boot.
