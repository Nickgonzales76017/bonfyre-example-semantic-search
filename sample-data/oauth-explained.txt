OAuth 2.0 is the industry standard protocol for authorization. It allows third-party applications to access user resources without exposing credentials. The four grant types are Authorization Code (most secure, for server-side apps), Implicit (simplified for SPAs, now deprecated), Client Credentials (machine-to-machine), and Resource Owner Password (direct username/password, discouraged). The Authorization Code flow with PKCE (Proof Key for Code Exchange) is recommended for both server and client apps. Tokens include access tokens (short-lived, for API calls) and refresh tokens (longer-lived, for obtaining new access tokens). JWTs (JSON Web Tokens) are commonly used as access tokens, containing claims about the user encoded in a signed payload. OpenID Connect extends OAuth 2.0 with an identity layer, providing standardized user info endpoints and ID tokens.
