Kubernetes is an open-source container orchestration platform that automates the deployment, scaling, and management of containerized applications. Originally designed by Google, it provides a framework to run distributed systems resiliently, handling failover, scaling patterns, and canary deployments. Pods are the smallest deployable units in Kubernetes, typically containing one or more containers that share storage and network resources. Services provide stable networking endpoints, while Deployments manage the desired state of pod replicas. The control plane makes global decisions about the cluster, such as scheduling, and detects and responds to cluster events like starting up a new pod when a deployment's replicas field is unsatisfied.
