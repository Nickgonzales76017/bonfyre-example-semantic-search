Machine learning is a subset of artificial intelligence that enables systems to learn and improve from experience without being explicitly programmed. The three main types are supervised learning (labeled training data), unsupervised learning (finding patterns in unlabeled data), and reinforcement learning (learning through trial and reward). Common algorithms include linear regression for continuous predictions, decision trees for classification, and k-means for clustering. The typical workflow involves data collection, preprocessing, feature engineering, model training, evaluation using metrics like accuracy or F1 score, and deployment. Overfitting occurs when a model memorizes training data rather than generalizing, which is mitigated through techniques like cross-validation, regularization, and dropout.
